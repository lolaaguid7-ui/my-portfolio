نبذة عني

أنا طالبة في السنة الثالثة بتخصص علوم الحاسب وتكنولوجيا المعلومات، ولدي شغف بتطوير الويب وتصميم واجهات المستخدم.

أعمل حاليًا على تطوير مهاراتي التقنية وتوسيع معرفتي في مجال البرمجة من خلال التعلّم المستمر والمشاريع العملية.

أسعى إلى بناء معرض أعمال يعكس تطوري ومهاراتي، واكتساب خبرات حقيقية تعزز سيرتي الذاتية وتساعدني على الاستعداد لسوق العمل.

أطمح مستقبلًا إلى أن أصبح مطوّرة ويب متكاملة (Full-Stack Developer)، قادرة على بناء مواقع وتطبيقات ويب من الواجهة الأمامية إلى الأنظمة الخلفية.

مهاراتي التقنية

  • HTML - بناء هيكل صفحات الويب
  • CSS - تصميم وتنسيق الصفحات
  • JavaScript - قيد التعلّم

أعمالي

01 - مشروع حمصة قهوة

موقع تعريفي لمقهى افتراضي

مشروع تدريبي لتصميم موقع مقهى يعرض هوية المكان، وقائمة المشروبات والأسعار، بالإضافة إلى نموذج طلب تفاعلي بسيط.

التقنيات: HTML، CSS، JavaScript بسيط

مشاهدة المشروع

02 - معرض أعمالي الشخصي

موقع شخصي لعرض مشاريعي ومهاراتي التقنية، والتعريف بخلفيتي الأكاديمية والخدمات التي أستطيع تقديمها.

التقنيات: HTML، CSS

لمشاهدة المشروع

03 - مشروع جامعي

سيتم إضافة تفاصيل المشروع الجامعي والتقنيات المستخدمة فيه.

04 — مشروع مخبز

موقع تعريفي لمخبز افتراضي

مشروع تدريبي يهدف إلى تصميم واجهة ويب لمخبز، مع التركيز على تنظيم المحتوى وعرض المنتجات بطريقة واضحة وجذابة، وتطبيق مهارات تطوير الواجهات الأمامية.
